DQ6 battle message pool - the 107 authored messages
==================================================================

These are battle messages that the NoPrgress translation left unwritten. In
play each one displays the game's own internal identifier, so a Goof-Off action
reads B1D2 and the confused-flail line reads M17D.

They live in a THIRD string system, separate from the Huffman message script
and from the name table:

  pointer table   $C1:5AD1, 76 entries of 3 bytes, ending exactly where the
                  Huffman message table at $C1:5BB5 begins
  payload         $F6:DEBD
  shape           8 messages per entry, 608 in all, $AC / $AE terminated
  encoding        the name-table byte charset plus the ligature dictionary at
                  $C3:FB50, not Huffman

Each row is  ---- <message ID in hex>  followed by the English.

NOTATION
  {XX}  a control byte, written where the game's own message puts it

  {B7} actor name     {B8} target name    {B3} a party member
  {B4} monster        {B5} item           {B2} spell or skill name
  {BB} a number       {BA} his / her / its
  {B9} him / her / it, and only ever as {B9}self
  {0D}{0E} the M and P of MP, which are control bytes rather than letters
  {AD} line break     {B1} {C2} {AF} window control

RULE FOLLOWED THROUGHOUT: a message uses exactly the control codes its own
Japanese uses, in the same places, and no others. Where the Japanese carries no
pronoun the English carries none either, which also keeps every line correct
whichever party member performs it and whatever the player named them.

This file carries no Japanese. The source text belongs to Enix and the
translation of the surrounding script to NoPrgress.
