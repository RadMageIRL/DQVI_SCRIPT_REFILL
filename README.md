# DQVI Script Refill

Completing the untranslated placeholder messages left behind in the NoPrgress
English fan translation of Dragon Quest VI for the SNES.

The shipped translation covers most of the script but leaves a block of messages
that were never written: in game they display their own message ID as decimal
digits. This project authors those messages from the Japanese source, in the
original translators' own voice, matching the vocabulary, register and layout
limits measured from the text they did finish.

## Status

Work in progress. The repo currently holds the method only. The completed script
and the patches land at release.

## Documentation

- [`docs/METHOD.md`](docs/METHOD.md) - how the message system was decoded, how
  the untranslated messages were identified, how the glyph map was built, and
  the authoring rules measured from the translators' own text.

No ROMs, patches or dumps are distributed here.
