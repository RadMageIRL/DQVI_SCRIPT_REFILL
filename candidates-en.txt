DQ6 Script Refill - the 421 authored messages
==================================================================

Message ID, the English written for it, and where one exists, the reasoning
or the precedent in NoPrgress's own script that it follows.

NOTATION
  |  page break     /  line break     {XX}  a control code
  {C0} {C9} {D3} and similar are runtime name inserts: the game substitutes
  a party member's name, so the text around them has to read correctly
  whatever the player called that character.

This file carries no Japanese. The source text belongs to Enix and the
translation to NoPrgress; anyone wanting to compare can decode both ROMs
with the published tooling. Where a note needed to quote the Japanese to
explain a choice, the quote is romanized.
